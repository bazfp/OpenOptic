Output options

Black-level correction uses the dark calibration frame. TIFFs hold the scanner's linear 16-bit data: not inverted or colour balanced, ready for a negative converter. Film type affects only the preview. Orientation is stored as the TIFF orientation tag.

Advanced

Sensor averaging applies to calibration reads, framing and frame scans. It reduces horizontal sampling at 1440/3600 dpi; there is no reduction at 7200 dpi. Recorded shading remains in use, so live level checks compare against a deletion-mode reference. This is separate from output line-pair averaging.

Longer exposure can be saved for later implementation. Scanning above 1× is blocked until fresh calibration and motor timing support are implemented.

seconds (default 1)

Warm-up applies only when the LED has been off.

The scanner samples twice as many lines as columns. Averaging line pairs and Lanczos-3 both give square pixels. Lanczos-3 aligns the colours and reduces the lines in one step: vertical detail is kept better, with less grain aliasing and slightly less noise, at about 1–3 seconds' extra processing. Very hard edges may show a faint halo. “Keep all lines” saves every line with separate X/Y dpi tags; most programs display it stretched.

Experimental, untested on hardware. Skips the unused CCD lines the official software inserts (1 at 3600 dpi, 2 at 7200) and speeds the motor to match; image size and exposure are unchanged. Vertical detail becomes slightly softer, and data arrives faster (up to 11 MB/s), so check for bands.

A is the button on GPIO3 (event 0x04), B the one on GPIO2 (event 0x02). Pressing one highlights its row here, so you can tell them apart. Presses are ignored while the scanner is busy, unless set to Stop.

Diagnostics

The button monitor logs every scanner event and every change of the GPIO registers (0x6C/0x6D) while you press the front buttons. Copy the log lines it ends with, so the buttons can be mapped to scanning.

The trace is saved in the roll folder; check it with tools/compare_trace.py. Dry run uses a simulated scanner and writes real files, so you can check naming and folders. Experimental page (custom resolution, crop, IR; unverified).
